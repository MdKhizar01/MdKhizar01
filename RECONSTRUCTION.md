# Reconstruction provenance

These projects were reconstructed in October 2026 from remembered project descriptions because the original source files were unavailable. They are new implementations, not recovered submissions. The retained D3 homework and lowest-cost-first-search folders elsewhere in this repository contain recovered files.

Do not attribute previous dataset sizes, model accuracies, cloud deployments, or assignment results to these reconstructions. Included demo data is synthetic. Run the documented commands on the intended dataset to obtain new results.

The distributed optimization example is an illustrative projected-gradient method with ring communication; it is not a verified reproduction of the original neural k-WTA research paper. The Java IR reconstruction uses simple suffix normalization rather than the original Porter stemmer. Diabetes predictions are software demonstrations, not clinical validation.
