# Machine Learning Configuration Explorer

D3.js visualization exploring how position, hue, and area encode synthetic machine learning configuration data. Includes five views: position, hue, area, a deliberately misleading view, and a repaired view.

## Run

Open `index.html` in a browser with internet access for the D3 CDN. The HTML includes embedded sample data, so no server or separate dataset download is required. `ml_configurations.csv` is included for reuse.

`version_1.html` through `version_5.html` open with their corresponding view selected.

## Data

Self-created synthetic teaching data; values are not measured model benchmark results.
