# Lowest-Cost-First Search

Python implementation of lowest-cost-first search for a delivery robot graph, using a heap-based frontier and accumulated arc costs.

## Run

```sh
python3 lowest_cost_first.py
```

Uses only Python's standard library. The included example searches from A to G and prints the expansion order, optimal path, and total cost.

Verified output: `A -> D -> H -> G`, total cost `11`.
