# Urban Environmental Sensor Explorer — reconstructed

D3 v7 linked scatter and time-series views with station/day filtering, tooltips, point selection, a linked details table, and reset. Both charts use consistent station colors and units. Points can be selected with Enter after keyboard focus.

Open `index.html` in a browser with internet access for the D3 CDN. Embedded data comprises 90 synthetic observations from three fictional stations over 30 days. It does not recover the instructor's original CSV or constitute real air-quality evidence.

This is a new approximation of the remembered CSCE 5320 interactive visualization assignment. It does not include the original user evaluation, sketches, screenshots, or validity report.
