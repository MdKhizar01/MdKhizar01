# Feature Engineering Labs

Selected original CSCE 5222 notebooks covering text features, review representations, image descriptors, dimensionality reduction, and audio features.

Open notebooks in Google Colab or Jupyter, inspect their imports, and supply the data files referenced in their loading cells. Dependencies differ by notebook; several retain Colab installation commands or local dataset paths. Outputs were cleared to avoid committing large embedded images and personal execution metadata. Notebook code is retained; the full set has not been rerun during import.

The separate [medicinal-leaf project](https://github.com/MdKhizar01/Feature-Engineering-Project) remains the featured classification project.
