# AI Search and Logic

Original Python coursework recovered from CSCE 5210 programming submissions.

- `crossword_sls.py`: any-conflict stochastic local search with random restarts and min-conflicts moves for a crossword CSP; includes solution validation and a 100-seed experiment.
- `pa3_logic.py`: bottom-up forward chaining and top-down backward chaining over a propositional knowledge base, including agreement checks.
- [Lowest-cost-first search](../lowest-cost-first-search): existing recovered graph-search implementation.

Requires Python 3 and its standard library. Run from this directory:

```bash
python crossword_sls.py
python pa3_logic.py
```

Personal Colab links and student identifiers were removed from the imported files. Algorithm logic is retained.
